# Tdrive Sync — إضافة Obsidian للمزامنة مع Tdrive

مزامنة ثنائية الاتجاه بين الـ Vault (ملاحظات `.md` والصور وPDF والصوت وغيرها) واستضافتك Tdrive عبر واجهتها REST مباشرةً، دون خادم وسيط.

> **حالة الاختبار:** اختُبرت المنطق والبروتوكول بـ 69 اختبارًا آليًا ضد خادم وهمي. **لم تُختبر بعد مع خادم Tdrive الحقيقي ولا داخل Obsidian على أندرويد/ويندوز** — راجع `docs/TEST-REPORT.md`. جرّب أول مرة على Vault تجريبي.

## التثبيت اليدوي
1. فك ضغط `tdrive-sync-1.0.0.zip` ستحصل على مجلد `tdrive-sync` فيه `main.js` و`manifest.json` و`styles.css`.
2. انسخ المجلد إلى `<مجلد الـ Vault>/.obsidian/plugins/tdrive-sync/`.
   - **ويندوز:** افتح مجلد الـ Vault، فعّل "إظهار العناصر المخفية"، وانسخ إلى `.obsidian\plugins\`.
   - **أندرويد:** بمدير ملفات يعرض المجلدات المخفية (مثل Files by Google أو Solid Explorer) انسخ المجلد إلى `<Vault>/.obsidian/plugins/`.
3. في Obsidian: الإعدادات ← Community plugins ← أوقف Restricted mode ← فعّل **Tdrive Sync** (أعد تحميل القائمة أو أعد تشغيل التطبيق إن لم يظهر).

## الإعداد
1. في Tdrive: Account ← API keys، أنشئ **مفتاحًا مخصصًا لهذه الإضافة** (قابلًا للإلغاء).
2. الإعدادات ← Tdrive Sync: الصق المفتاح، تحقق من عنوان الخادم `https://tdriver.x2o.workers.dev`، وحدّد المجلد البعيد (الافتراضي `/Obsidian/<اسم الـ Vault>/`).
3. اضغط **اختبار** ثم **فحص شكل استجابات API** (يكتب أسماء الحقول فقط في السجل لتأكيد التوافق).
4. جرّب أولًا نمط **رفع فقط** على Vault تجريبي، ثم **ثنائية الاتجاه**.

## الأوامر (Command Palette)
Tdrive Sync: Test Connection · Sync Now · Approve Pending Deletions · Upload Current File · Download Remote Changes · View Conflicts · View Sync Log · Pause Sync · Resume Sync. إضافةً لأيقونة الشريط الجانبي وعنصر شريط الحالة (سطح المكتب).

## الإعدادات
| الإعداد | الوصف |
|---|---|
| عنوان الخادم | HTTPS إجباري (ما عدا localhost للتطوير). المفتاح لا يُرسل لأي نطاق آخر. |
| API Key | يُحفظ نصًّا عاديًا في `data.json` داخل مجلد الإضافة. |
| المجلد البعيد | جذر المزامنة على Tdrive. |
| نمط المزامنة | ثنائية الاتجاه / رفع فقط / تنزيل فقط. |
| سياسة الحذف | نقل إلى السلة (سلة Tdrive أو سلة Obsidian — قابلة للاسترجاع) أو إيقاف الحذف كليًا. لا حذف نهائي أبدًا. |
| حد الحذف | إن تجاوز عدد الحذف المطلوب هذا الحد تُحجب كل عمليات الحذف في تلك الجولة. |
| مزامنة تلقائية | بالدقائق؛ تعمل أثناء فتح التطبيق فقط. |
| الاستثناءات | أنماط glob (`Private/**`, `**/*.tmp`). كل ما يبدأ بنقطة (`.obsidian`, `.git`, `.trash`) مستثنى دائمًا، وكذلك سجل المزامنة. |

## التعارضات
إذا تغيّر الملف محليًا وبعيدًا منذ آخر مزامنة: لا يُستبدل شيء. تُحفظ النسخة البعيدة محليًا باسم `الاسم (Tdrive conflict التاريخ).md` ويُجمَّد المسار. افتح **View Conflicts** واختر: الاحتفاظ بالمحلية / البعيدة / النسختين / إلغاء. لا تُحذف نسخة التعارض تلقائيًا.

## الأمان
- استخدم مفتاحًا مخصصًا وألغِه من Tdrive إذا فُقد الجهاز أو شاركت مجلد `.obsidian`.
- لا تُطبع المفاتيح في السجلات (تُحجب `tdk_…`)، ولا `eval`، ولا تحميل كود من الخادم.
- أخطاء الاتصال أو الاستجابات الناقصة توقف الجولة قبل أي حذف أو استبدال.

## القيود
- تعتمد على سلوك API غير الموثق تفصيليًا (انظر `docs/API-CONTRACT.md` ← الافتراضات). إن اختلف الخادم الحقيقي، أرسل لي مخرجات "فحص شكل استجابات API".
- تغيير مسار/اسم ملف = ملف جديد + نقل القديم لسلة Tdrive (لا يوجد نقل ذكي).
- تُحمَّل الملفات الكبيرة كاملة في الذاكرة أثناء الرفع/التنزيل؛ تجنّب مئات الميغابايت على أجهزة ضعيفة.
- لا مزامنة في الخلفية عندما يعلّق Obsidian (أندرويد).
- اكتشاف التعديل البعيد يعتمد على المعرّف والحجم ووقت التعديل الذي يرجعه الخادم.

## سجل التغييرات
- **1.0.5** — إصلاحات المجلدات والحذف والتتبع:
  - **الحذف المحجوب لم يعد صامتًا:** عند تجاوز حد الحذف (مثلًا حذف أو إعادة تسمية مجلد فيه أكثر من 10 ملفات) تُحفظ القائمة وتظهر في لوحة الحالة مع إشعار، وأمر جديد **Approve Pending Deletions** يعرض الملفات ويطبّق الحذف (إلى السلة) بعد موافقتك. الموافقة لا تتجاوز حماية "الـ Vault/المجلد البعيد فارغ". سابقًا كان الحذف يتجمّد للأبد وتبقى نسخ مكررة بعد إعادة تسمية مجلد.
  - **كل التحذيرات تُكتب في سجل المزامنة** (كانت تُهمل ولا تظهر في أي مكان).
  - **المجلدات الفارغة تُزامَن:** مجلد جديد فارغ محليًا يُنشأ على Tdrive، والعكس، ثم يُتتبَّع فيُنقل حذفه لاحقًا.
  - **لا يُنقل مجلد محلي للسلة إن بقي فيه محتوى مخفي** لا يراه فهرس Obsidian.
  - **حفظ السجل أثناء التشغيل** كل 20 عملية، فلا تضيع نتائج المزامنة إن أُغلق Obsidian فجأة (أندرويد).
- **1.0.4** — حذف المجلدات يعمل الآن في الاتجاهين (محليًا ← Tdrive، وTdrive ← محليًا) بشرط أن يكون المجلد فارغًا، وبنفس ضمانات حذف الملفات. أمر جديد **Clean Empty Remote Folders** لتنظيف المجلدات الفارغة التي تركتها النسخ السابقة.

## التحديث والإزالة
- **تحديث:** استبدل `main.js` و`manifest.json` و`styles.css` بالجديدة وأعد تحميل الإضافة. ملف `sync-state.json` (السجل) و`data.json` (الإعدادات) يبقيان.
- **إزالة:** عطّل الإضافة ثم احذف مجلد `tdrive-sync`. ملفاتك على Tdrive وفي الـ Vault لا تتأثر. لإلغاء الوصول ألغِ المفتاح من Tdrive.
