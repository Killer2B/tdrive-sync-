# Tdrive Sync — إضافة Obsidian للمزامنة مع Tdrive

مزامنة ثنائية الاتجاه بين الـ Vault (ملاحظات `.md` والصور وPDF والصوت وغيرها) واستضافتك Tdrive عبر واجهتها REST مباشرةً، دون خادم وسيط.

> **حالة الاختبار:** **80 اختبارًا آليًا** ضد خادم وهمي (كلها ناجحة) + **تحقق مباشر** على خادم Tdrive الحقيقي (رفع/تنزيل متوازٍ، تشفير، حذف مجلد). لم يُشغَّل بعد داخل تطبيق Obsidian فعليًا. راجع `docs/TEST-REPORT.md`. جرّب أول مرة على Vault تجريبي.

## أبرز الميزات (1.1.0)
- **رفع وتنزيل متوازيان** للأجزاء (أسرع للملفات الكبيرة)، مع **ذاكرة أقل** (تجزئة بلا نسخ).
- **حجم جزء التنزيل قابل للضبط**، وحجم جزء الرفع يتّبع ما يفرضه الخادم لضمان القبول.
- **شريط تقدم** لكل ملف كبير في شريط الحالة.
- **أقصى حجم ملف** لتجاهل الفيديوهات الضخمة، و**Wi-Fi فقط / تأجيل الملفات الكبيرة على الخلوي**.
- **تشفير من طرف العميل (E2EE)** اختياري: لا يرى الخادم إلا نصًا مشفّرًا.
- **مزامنة تلقائية عند التعديل** (بمهلة debounce) مختلطة بالمزامنة الدورية.
- **تصدير سجل الأخطاء** إلى ملف بضغطة واحدة.
- حذف المجلدات في الاتجاهين، التعارضات المحفوظة، وضمانات صارمة ضد أي حذف غير مقصود.

## التثبيت اليدوي
1. ضع المجلد `tdrive-sync` (فيه `main.js` و`manifest.json` و`styles.css`) في `<مجلد الـ Vault>/.obsidian/plugins/tdrive-sync/`.
   - **ويندوز:** فعّل "إظهار العناصر المخفية" ثم انسخ إلى `.obsidian\plugins\`.
   - **أندرويد:** بمدير ملفات يعرض المجلدات المخفية انسخ إلى `<Vault>/.obsidian/plugins/`.
2. في Obsidian: الإعدادات ← Community plugins ← أوقف Restricted mode ← فعّل **Tdrive Sync**.

## الإعداد
1. في Tdrive: Account ← API keys، أنشئ **مفتاحًا مخصصًا لهذه الإضافة** (قابلًا للإلغاء).
2. الإعدادات ← Tdrive Sync: الصق المفتاح، تحقق من عنوان الخادم `https://tdriver.x2o.workers.dev`، وحدّد المجلد البعيد (الافتراضي `/Obsidian/<اسم الـ Vault>/`).
3. اضغط **اختبار** ثم **فحص شكل استجابات API**.
4. جرّب أولًا نمط **رفع فقط** على Vault تجريبي، ثم **ثنائية الاتجاه**.

## الأوامر (Command Palette)
Test Connection · Sync Now · Approve Pending Deletions · Upload Current File · Download Remote Changes · Clean Empty Remote Folders · View Conflicts · View Sync Log · **Export Sync Log** · Pause Sync · Resume Sync. إضافةً لأيقونة الشريط الجانبي وعنصر شريط الحالة.

## الإعدادات
| الإعداد | الوصف |
|---|---|
| عنوان الخادم / API Key | HTTPS إجباري (ما عدا localhost). المفتاح لا يُرسل لأي نطاق آخر. |
| المجلد البعيد | جذر المزامنة على Tdrive. |
| نمط المزامنة | ثنائية الاتجاه / رفع فقط / تنزيل فقط. |
| سياسة الحذف | نقل إلى السلة (Tdrive/Obsidian) أو إيقاف الحذف كليًا. لا حذف نهائي أبدًا. |
| حد الحذف | تجاوز العدد ⇒ تُحجب كل عمليات الحذف تلك الجولة وتظهر للمراجعة. |
| المزامنة التلقائية | بالدقائق (0 = معطلة). تعمل أثناء فتح التطبيق. |
| المزامنة عند التعديل | تشغّل مزامنة بعد مهلة من آخر تعديل محلي. |
| حجم جزء الرفع/التنزيل | بالأميال (0 = تلقائي للرفع). |
| عدد الأجزاء المتوازية | 1 = تسلسلي، 3-4 يسرّع الملفات الكبيرة. |
| أقصى حجم ملف | 0 = بلا حد. تُتجاهل الملفات الأكبر (لا رفع ولا تنزيل). |
| Wi-Fi فقط / تأجيل الخلوي | تجنّب استهلاك البيانات على الشبكة الخلوية. |
| E2EE | تشفير المحتوى قبل الرفع بعبارة مرور. |
| الاستثناءات | أنماط glob. كل ما يبدأ بنقطة مستثنى دائمًا. |

## الأمان
- استخدم مفتاحًا مخصصًا وألغِه من Tdrive إذا فُقد الجهاز أو شاركت `.obsidian`.
- لا تُطبع المفاتيح في السجلات، ولا `eval`، ولا تحميل كود من الخادم.
- أخطاء الاتصال أو الاستجابات الناقصة توقف الجولة قبل أي حذف أو استبدال.
- **E2EE:** عند التفعيل لا يرى الخادم إلا نصًا مشفّرًا (AES-256-GCM). استخدم عبارة مرور طويلة؛ لا استرجاع بدونها. أسماء الملفات تبقى ظاهرة.

## التعارضات
إذا تغيّر الملف محليًا وبعيدًا منذ آخر مزامنة: لا يُستبدل شيء. تُحفظ النسخة البعيدة محليًا باسم `الاسم (Tdrive conflict التاريخ).md` ويُجمَّد المسار. افتح **View Conflicts** واختر: الاحتفاظ بالمحلية / البعيدة / النسختين / إلغاء.

## القيود
- **الذاكرة:** تقرأ واجهة Obsidian الملف كاملًا؛ خفّضنا الذاكرة إلى ~1× لكن ملفات بمئات الميغابايت قد تثقل الأجهزة الضعيفة (استخدم "أقصى حجم ملف").
- تعتمد على سلوك API غير موثّق تفصيليًا (انظر `docs/API-CONTRACT.md`)؛ تأكدنا من أهم السلوكيات باختبار حي.
- مزامنة الخلفية معطّلة عندما يعلّق Obsidian (أندرويد)؛ يعمل الفاصل والتغيير أثناء فتح التطبيق فقط.
- اكتشاف الشبكة الخلوية أفضل جهد (إذا لم يتوفر `navigator.connection` تُعامل الشبكة كآمنة).
- تغيير مسار/اسم ملف = ملف جديد + نقل القديم لسلة Tdrive.

## سجل التغييرات
- **1.1.0** — نسخة إنتاجية:
  - رفع/تنزيل **متوازٍ** للأجزاء + **ذاكرة أقل** (تجزئة بلا نسخ).
  - إصلاح جوهري للرفع المجزّأ على Tdrive الحقيقي: حجم الجزء الملزِم يُقرأ من جلسة الرفع (`chunkSize`) والبصمة تُبنى وفقًا له.
  - تنزيل متوازٍ آمن (يتحقق من طول كل جزء ويكمله إن اقتُطع).
  - **E2EE** اختياري، **حد حجم الملف**، **Wi-Fi فقط/تأجيل الخلوي**، **مزامنة عند التعديل**، **شريط تقدم**، و**تصدير السجل**.
  - إعدادات جديدة: حجم الأجزاء، التوازي، أقصى حجم، الشبكة، التشفير.
- **1.0.6** — إصلاح حذف المجلدات: الصيغة الصحيحة للخادم `{name, path(الأب)}` بدل المسار الكامل (كانت `400 Invalid path`).
- **1.0.5** — إصلاحات المجلدات والحذف: عرض الحذف المحجوب والموافقة عليه، تسجيل كل التحذيرات، مزامنة المجلدات الفارغة، حفظ السجل أثناء التشغيل.
- **1.0.4** — حذف المجلدات في الاتجاهين + أمر Clean Empty Remote Folders.

## التحديث والإزالة
- **تحديث:** استبدل `main.js` و`manifest.json` و`styles.css` بالجديدة وأعد تحميل الإضافة. ملف `sync-state.json` و`data.json` يبقيان.
- **إزالة:** عطّل الإضافة ثم احذف مجلد `tdrive-sync`. ملفاتك لا تتأثر.
